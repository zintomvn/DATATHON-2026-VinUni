# Kế hoạch phân tích dữ liệu (PLAN.md)

## 1. Khám phá dữ liệu (EDA)

### Khám phá 1 biến (Univariate)
- **Số**
- **Phân loại**
- Missing data
- Outlier
- Noise
- Visualization: Tableau + Power BI

### Khám phá 2 biến (Bivariate) - Tương quan trước khi vẽ biểu đồ
- **Số - Số:** Pearson -> Vẽ biểu đồ
- **Số - Phân loại:** Cross table
- **Phân loại - Phân loại:** Chi-square (Cramer's V) -> Vẽ biểu đồ
